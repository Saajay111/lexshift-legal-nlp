# Public Release Checklist

- [ ] Research claims match completed analyses and are not overstated.
- [ ] CUAD and SEC source terms have been reviewed.
- [ ] No raw contract text is included without permission.
- [ ] No secrets, tokens, private configuration, or credentials are present.
- [ ] No personal contact details or unnecessary account identifiers are present.
- [ ] Notebook outputs and logs have been reviewed.
- [ ] Local paths, environment details, and private manifests are removed.
- [ ] Dependencies and licenses are documented.
- [ ] Tests and automated quality checks pass.
- [ ] Data, code, and paper versions are identified.
- [ ] Limitations and intended-use disclaimer are visible.
